# About Me – Developer Portfolio

A personal **"About Me"** portfolio / curriculum page that showcases programming skills, career timeline, and featured projects. Built with pure HTML, CSS, and JavaScript – no frameworks, no build step required.

## 🚀 Features

- **Hero section** with animated intro and call-to-action buttons
- **About section** with animated statistics counters
- **Skills section** with animated progress bars and technology badges
- **Career & Education timeline** with scroll-reveal animations
- **Projects showcase** with tech tags
- **Contact section** linking to GitHub, email, and LinkedIn
- Fully **responsive** design (mobile, tablet, desktop)
- Sticky **navbar** with active-link highlighting and mobile hamburger menu
- Dark colour scheme with a modern gradient aesthetic

## 📂 File structure

```
About-Me/
├── index.html   # Main page markup
├── styles.css   # All styling (dark theme, responsive grid, animations)
└── script.js    # Interactivity (counters, skill bars, timeline reveal)
```

## 🛠️ Usage

Simply open `index.html` in any modern browser — no installation or build step needed.

```bash
# Clone the repo
git clone https://github.com/Juanjooooooooooo/About-Me.git
cd About-Me

# Open in browser (macOS)
open index.html

# Open in browser (Linux)
xdg-open index.html
```

## 🎨 Customisation

Edit `index.html` to update your name, bio, work experience, and projects.  
Adjust colours in the `:root` block at the top of `styles.css`.
